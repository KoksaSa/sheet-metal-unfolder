Калибровочная поправка станка

Поправка применяется ко всем технологическим рекомендациям выбранного станка. Это позволяет отдельно учитывать текущее состояние станка. Для безопасности поправку нужно менять только после контрольного гиба.

База данных

Все данные хранятся локально в браузере этого компьютера. Экспортируйте JSON как резервную копию и для переноса базы на другой компьютер.

Как рассчитывается Y

  1. Система сначала ищет испытания с совпадающими станком, материалом, толщиной, направлением волокон и V.
  2. Если есть точки с близкой длиной гиба и требуемым углом, используется их зависимость «Y → фактический угол».
  3. Если точного совпадения нет, ближайшие реальные испытания получают меньший вес по мере увеличения отличия параметров.
  4. Для двух соседних точек по углу используется линейная интерполяция. Если нужный угол находится вне диапазона измеренных точек, выполняется осторожная экстраполяция и доверие снижается.
  5. После расчёта добавляется текущая калибровочная поправка выбранного станка.
  6. Чем больше реальных испытаний и чем ближе они к заданным параметрам, тем выше уровень доверия.
Важно: этот модуль не знает механики конкретного контроллера и не может гарантировать универсальную физическую формулу Y. Он строит эмпирическую характеристику именно по вашим реальным пробным гибам. Это принципиально важно для старых прессов без индивидуального распределения усилий по цилиндрам.
