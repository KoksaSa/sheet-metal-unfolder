# Sheet Metal Unfolder

Расчёт и визуализация развёрток деталей из листового металла. Рисуете профиль — приложение строит плоскую развёртку с учётом толщины, радиуса гиба и K-фактора.

## 🌐 Сайт

Проект развёрнут на GitHub Pages:

👉 **[https://koksasa.github.io/sheet-metal-unfolder/](https://koksasa.github.io/sheet-metal-unfolder/)**

## ✨ Возможности

- **Построение профиля** — рисование точек на координатной сетке с привязкой к сетке и углам
- **Автоматическая развёртка** — плоская заготовка с линиями гиба, размерами и припусками
- **3D-превью** — изометрический вид согнутого профиля с вращением и зумом
- **Кайма (hem)** — загибы краёв с расчётом припуска
- **Экспорт** — DXF, SVG, PNG, JSON
- **Материалы** — пресеты металлов с плотностью и K-фактором
- **Имперские единицы** — переключение RU / EN
- **Сохранение проекта** — автосохранение в localStorage

## 🚀 Запуск локально

Проект статический — просто откройте `index.html` в браузере:

```bash
git clone https://github.com/KoksaSa/sheet-metal-unfolder.git
cd sheet-metal-unfolder
start index.html   # Windows
# или откройте файл в браузере
```

## 🛠 Технологии

- Vanilla JavaScript (ES6+), без сборщиков
- Tailwind CSS (CDN) + кастомные стили
- Canvas 2D для чертежей и 3D-превью
- [Lucide](https://lucide.dev/) — иконки

## 📁 Структура проекта

```
├── index.html          # DOM-структура и разметка
├── css/
│   └── styles.css      # Кастомные стили
└── js/
    ├── app.js          # Инициализация, горячие клавиши
    ├── canvas.js       # 2D-чертёж, 3D-превью, зум/панорамирование
    ├── data.js         # Пресеты материалов
    ├── engine.js       # Расчёт развёртки, DXF/SVG генерация
    ├── i18n.js         # RU/EN переводы
    ├── state.js        # Состояние приложения, undo/redo, экспорт
    └── ui.js           # Рендер интерфейса, диалоги редактирования
```
