# Sheet Metal Unfolder v5.0

Расчёт и визуализация развёрток деталей из листового металла. Рисуете профиль — приложение строит плоскую развёртку с учётом толщины, радиуса гиба и K-фактора.

## 🌐 Сайт

Проект развёрнут на GitHub Pages:

👉 **[https://koksasa.github.io/sheet-metal-unfolder/](https://koksasa.github.io/sheet-metal-unfolder/)**

## ✨ Возможности

- **Построение профиля** — рисование точек на координатной сетке с привязкой к сетке и углам
- **Автоматическая развёртка** — плоская заготовка с линиями гиба, размерами и каймами
- **3D-превью** — изометрический вид согнутого профиля с вращением и зумом
- **Реалистичная симуляция гибки (2D и 3D)** — пуансон опускается в V-матрицу (air bending), металл плавно деформируется; угол гиба вычисляется по глубине погружения. Гибы накапливаются — как на реальном станке. **v5.0: в местах выполненных гибов — дуги заданного радиуса** (R и K из таблицы металла): острый излом заменяется касательной дугой нейтрального радиуса R + K·T, во время анимации лист плавно «заворачивается» на дугу (радиус от ∞ до R), пуансон касается вогнутой поверхности дуги
- **3D-симуляция с шагами** — полноэкранная 3D-сцена: кнопки «Плоская» → «Шаг N» → «Полная», вращение ЛКМ, панорама ПКМ, зум колёсиком/пинчем
- **Кайма (hem)** — загибы краёв с расчётом припуска
- **Экспорт** — DXF развёртки, готовый чертёж A4 с листами «Последовательность гибки» (v4.9: кнопки SVG/PNG/JSON/PDF убраны)
- **Материалы** — пресеты металлов с плотностью и K-фактором
- **Инструменты гибки** — выбор матрицы (V) и пуансона (R), импорт своих DXF-профилей
- **STEP-инструмент «Развёртка крестом»** — кнопка «Загрузить деталь» в левой панели открывает отдельный инструмент (step-v-gib.html): импорт 3D-деталей STEP (ядро OCCT), развёртка крестом для поддонов, разрез плоскостью, 2D-симуляция, экспорт DXF
- **Калькулятор Y гиба (v5.0)** — кнопка «Калькулятор Y гиба» в левой панели открывает y-calculator.html: эмпирическая база испытаний станка (Y → фактический угол), интерполяция/регрессия рекомендуемого Y для нужного угла, калибровка станка, экспорт/импорт базы. Чертёж «Последовательность гибки» показывает колонку **«Y станка»** для каждого шага, рассчитанную по этой базе
- **Двуязычный интерфейс** — RU / EN
- **Тёмная тема**
- **Сохранение проекта** — автосохранение в localStorage

## 🚀 Запуск локально

Проект статический — просто откройте `index.html` в браузере:

```bash
git clone https://github.com/KoksaSa/sheet-metal-unfolder.git
cd sheet-metal-unfolder
start index.html   # Windows
# или откройте файл в браузере
```

Интернет не требуется — иконки Lucide и CSS лежат локально (`js/vendor/`, `css/`).

## 🛠 Технологии

- Vanilla JavaScript (ES6+), без сборщиков — классические скрипты, порядок подключения важен (см. `index.html`)
- Tailwind CSS (прекомпилированный `css/tailwind.css`; исходник — `css/tailwind-input.css` + `tailwind.config.js`)
- Canvas 2D для чертежей, 2D/3D-симуляции
- [Lucide](https://lucide.dev/) — иконки (локальная копия в `js/vendor/lucide.min.js`)

## ⚙️ Симуляция гибки

Включите режим «Симуляция» в панели инструментов — на холсте появятся пуансон (сверху, красный) и V-матрица (снизу, синяя). Кликните по маркеру точки гиба, затем ещё раз — запустится анимация: пуансон опускается в матрицу, металл плавно сгибается.

Кнопка **3D Сим** открывает полноэкранную 3D-симуляцию: кнопки шагов внизу («⏵ Плоская», «Шаг 1…N», «↺ Сброс», «▶ Полная»), в шапке — кнопки видов «Вид слева»/«Вид справа», вращение ЛКМ, панорама ПКМ, зум колёсиком. Подписи локализованы (ru/en).

Профиль можно не рисовать мышью, а **загрузить из DXF**: кнопка **«Импорт профиля DXF»** в левой панели (v4.9: перенесена сюда из плиток шаблонов) — выберите .dxf файл с профилем из линий (LINE/LWPOLYLINE/POLYLINE). Единицы (дюймы/мм) определяются автоматически, коллинеарные точки объединяются, при нескольких контурах берётся самый длинный.

Угол гиба вычисляется по формуле air bending: `depth = (V/2) × tan(halfAngle)`, где V — ширина V-ручь матрицы.

### Радиусы гибов в симуляции (v5.0)

Выполненные гибы рисуются **дугами по таблице металла**: нейтральный радиус `Rn = R + K·T` (согласован с развёрткой — длина дуги = припуск гиба). Дуга вписана в угол и касательна к обеим полкам; полки укорачиваются на касательные длины `t = Rn·tan(φ/2)`, как у реальной детали. Во время анимации лист **«заворачивается» на дугу** с сохранением длины материала: радиус меняется от ∞ (плоский лист) до Rn (готовый гиб) — как при реальной свободной гибке. Пуансон заканчивает ход касанием вогнутой поверхности дуги (по биссектрисе V-складки). На коротких полках дуга автоматически уменьшается, чтобы не «съедать» соседнюю геометрию; каймы (hem) сохраняют собственные дуги-«капли» из v4.9.

### Калькулятор Y (v5.0)

Кнопка **«Калькулятор Y гиба»** (бирюзовая, в левой панели) открывает y-calculator.html с предзаполненными параметрами текущего проекта (материал, толщина, V матрицы, ширина заготовки, угол 90°). Оператор записывает **реальные пробные гибы** (какой Y выставил — какой угол получился); по базе строится зависимость «Y → угол», и калькулятор рекомендует Y для нужного угла (интерполяция/взвешенная регрессия + поправка станка). Подсказка «Мин. полка гиба» ориентируется по V. База хранится в localStorage (экспорт/импорт JSON).

На чертеже «Последовательность гибки» появляется колонка **«Y станка»**: для каждого шага по базе калькулятора рассчитывается Y для нужного угла гиба с текущими материалом/толщиной/V/шириной — какое положение Y выставить на станке. Нет испытаний — прочерк «нет базы».

## 🔄 Что нового в v5.0

1. **Радиусы в местах гиба (2D- и 3D-симуляция)** — раньше линии
   просто «ломались» в точках гиба без заданного радиуса, хотя радиус
   задан в таблице металла. Теперь каждый выполненный гиб рисуется
   **касательной дугой нейтрального радиуса Rn = R + K·T** (R и K —
   из панели металла): дуга вписана в угол, касательна к обеим полкам,
   полки укорачиваются на касательные длины t = Rn·tan(φ/2). Длина
   средней линии сохраняется: длина дуги = припуск гиба (BA) из
   развёртки — симуляция и развёртка согласованы. Работает в 2D, в 3D
   (полоса металла образует цилиндрическую поверхность) и на чертеже
   «Последовательность гибки» (мини-контуры шагов).
2. **Анимация «заворачивания»** — во время гибки дуга не «выскакивает»
   готовой: лист плавно заворачивается на неё с СОХРАНЕНИЕМ длины
   материала (длина дуги по нейтральной линии постоянна = BA, радиус
   меняется от ∞ при плоском листе до Rn при законченном гибе) — как
   при реальной свободной гибке. Разгибание работает в обратную
   сторону.
3. **Пуансон касается дуги** — вершина пуансона заканчивает ход на
   ВНУТРЕННЕЙ (вогнутой) поверхности дуги гиба (по биссектрисе
   V-складки), а не прокалывает металл к линии гиба. В покое пуансон
   по-прежнему отведён вверх.
4. **Подписи углов гибов** — точные: фактический угол поворота в
   вершине фиксируется до вставки дуг (раньше считался по соседним
   точкам массива и на хордах дуги «проседал» бы). Маркеры гибов
   остаются на виртуальном острие (линия гиба = ось пуансона, как на
   развёртке).
5. **Калькулятор Y гиба** — новый инструмент (y-calculator.html,
   кнопка «Калькулятор Y гиба» в левой панели): эмпирическая база
   испытаний станка «Y → фактический угол», рекомендация Y для
   нужного угла, калибровочные поправки станка, машины, история
   испытаний, экспорт/импорт JSON. Открывается с предзаполненными
   параметрами текущего проекта; подсказка минимальной полки по V.
6. **Колонка «Y станка» на чертеже** — в таблице «Последовательность
   гибки» для каждого шага показывается Y-положение станка для
   нужного угла, рассчитанное по базе калькулятора (общий localStorage
   с y-calculator.html): значение + уровень доверия + метод. Нет базы —
   прочерк.

## 🔄 Что нового в v4.9

1. **Кайма — плавный заворот по дуге на 180°** — раньше кайма (hem) в
   2D- и 3D-симуляции выглядела как резкий излом: линия «ломалась» в
   точке гиба каймы, а загиб 180° был острым отражением. Теперь кайма
   заворачивается аккуратной полукруглой дугой-«каплей» закрытого типа:
   дуга радиусом T/2 по средней линии (внешнее скругление радиусом T),
   обратная нога идёт параллельно основе на расстоянии T — полосы
   металла вплотную, как у настоящей закрытой каймы. Длина средней
   линии сохранена (π·r + нога = припуск каймы из развёртки), так что
   развёртка и симуляция согласованы. Точки дуги не отмечаются
   кружками вершин; в 3D внешняя труба заворота закрыта обратными
   гранями, вырожденные лицевые «плавники» не рисуются.
2. **Кайма в начале профиля — правильное направление** — раньше
   удлинение каймы на первой вершине отражалось НАЗАД и «свисало» за
   край заготовки с артефактной линией к следующей точке. Теперь линия
   гиба = дальний конец удлинения (та же точка, что линия гиба каймы в
   развёртке), край P0 заворачивается ВПЕРЁД по дуге и ложится поверх
   первого сегмента — как у реальной каймы и как в подсказке-«крючке»
   на холсте рисования. Концевая и внутренняя каймы гнутся назад, как
   раньше.
3. **Кнопка «Импорт профиля DXF»** — импорт профиля из DXF перенесён
   из плитки «DXF» сетки шаблонов в полноценную кнопку левой панели
   (синяя, под таблицей точек); плитка из шаблонов убрана — сетка снова
   содержит только фигуры-пресеты.
4. **«Скачать dxf развертки»** — кнопка экспорта DXF переименована
   (раньше просто «Скачать DXF»; EN: «Download flat pattern DXF»).
5. **Упрощение панели** — по запросу пользователя убраны кнопки:
   «Скачать SVG», «Скачать PNG», «Белый PNG», значки импорта/экспорта
   JSON и PDF (в шапке), а также SVG/PNG в мобильной панели развёртки.
   Остались только чертёж и DXF.

## 🔄 Что исправлено в v4.2

1. **Поворот заготовки «↕Y» и следующий гиб (главный фикс)** — раньше после физического
   переворота заготовки вокруг оси X следующий гиб применял переворот **дважды**
   (один раз — «запекался» между гибами в `bendStepMeta`, второй — глобально в конце
   расчёта профиля). Из-за этого заготовка визуально зеркалилась обратно, а гиб шёл
   **вниз**, хотя на реальном станке пуансон всегда давит сверху и гиб выполняется
   **вверх**. Сценарий: Z-профиль → 1-й гиб (Г-образно) → «↕Y» → 2-й гиб.
   Теперь:
   - переворот применяется **один раз** — зеркалом между гибами с чётностью по XOR
     (переворот + возврат = два зеркала = исходная ориентация);
   - в конце применяется только **дельта** — «заготовку перевернули ПОСЛЕ последнего
     гиба» (просмотр текущего положения детали);
   - направление гиба считается **в системе станка**: при перевёрнутой заготовке гиб
     относительно детали инвертируется, поэтому на станке он всегда выполняется вверх,
     а накопленная геометрия детали остаётся верной (отображение = (P?M:I) ∘ геометрия
     детали, где P — чётность переворота, M — зеркало y→−y).
2. **Упор (stopper) при перевёрнутой заготовке** — метаданные шага (`bendStepMeta`)
   теперь записываются ДО расчёта предгибного профиля: раньше переворот текущего гиба
   не учитывался, и упор со `stopperDist` ставились по НЕперевёрнутой заготовке.
3. **Лицевая сторона (2D)** — теперь инвертируется при физическом перевороте всегда
   (и на плоской заготовке), а не только при согнутых гибах.
4. **3D-симуляция: лицевая сторона исторических шагов** — чётность берётся из
   `bendStepMeta` гиба текущего шага (согласована с отображаемой геометрией), а не из
   текущего глобального `S.simFlipY`.
5. **Живое 3D-зеркало 2D-анимации** — дельта переворота больше не применяется поверх
   «запечённых» переворотов (двойное зеркало в 3D-виде устранено).
